4)WORA
  WORA  : Write Once Run Anywhere
 WORA means Write once Run Anywhere :It Means we need to write a program only once and it can be run on any platform(anywhere)
 java is platform independence because of this nature .In java we can write a program only once it can run on any platform because of bytecode after java program is compiled it generates bytecode because of this byte code and jvm we can run program anywhere.
   how : IAfter java program is compiled and byte code is generated it can run on anyplatform without changing anything because every platform has its dedicated JVM Due to this we can write program only once and run on any platform >Thats why java is called as platform independence.

Data Types

Data types are the types of data.It tells what type of data that variables can store inside the memory.
Data types are used to indicate the type of data that variables are storing.

Data types are 2 types
  1)Premitive Data types(8)
  2)Non premetive Data types(Infinite)
  
 1)Premitive datatypes
  -Premitive datatypes are type which are defined by java
  -It has fixed size
  -It stores single values
  -These has default values
  -There are 8 premitive datatypes are there

  
  
 2)Non premitive datatypes
  - Non-Premitive datatypes are defined by the programmers or developer.
  -It does't has fixed size 
  -It can store multiple or complex data
  -there are infinite number of datatypes are there
  -these data types has no default values
  -every class is a data type
